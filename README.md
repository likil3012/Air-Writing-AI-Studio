# 🖐️ Air Writing AI Studio

A real-time computer vision project that allows users to write and interact with a virtual canvas using hand gestures through a webcam.

## ✨ Features

- ✍️ Real-time air writing
- 👥 Two-hand tracking
- 🦴 Hand skeleton detection
- 👈 Left and right hand identification
- 🎨 Multiple pen colors
- 📏 Adjustable pen size
- 🧹 Eraser mode
- ↩️ Undo functionality
- 🗑️ Clear canvas
- 🔺 Shape mode
- 🔣 Symbol selection
- 💾 Save drawings
- 🔤 OCR text recognition

## 🛠️ Technologies

- Python
- OpenCV
- MediaPipe
- NumPy
- Tesseract OCR

## 🎮 Gesture Controls

| Gesture | Action |
|---|---|
| ☝️ Right Index | Write |
| 🤏 Right Pinch | Pause |
| ✊ Right Fist | Clear |
| 👍 Right Thumb | Undo |
| 🤏 Left Pinch | Change Color |
| ✌️ Left Two Fingers | Eraser |
| ☝️ Left Index | Change Symbol |
| 👍 Left Thumb Up | Increase Pen Size |
| 👎 Left Thumb Down | Decrease Pen Size |

## ⌨️ Keyboard Controls

| Key | Action |
|---|---|
| S | Save |
| R | OCR |
| C | Clear |
| U | Undo |
| + | Increase Pen Size |
| - | Decrease Pen Size |
| Q | Exit |

## 🚀 Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python air_writing_stud
```

- Python 3.12
- Webcam
- Tesseract OCR
